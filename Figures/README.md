[Figure 4](https://github.com/RaphaLevy/Environmental_Drivers_of_Malaria/blob/main/Figures/Paper/local_sensitivity_R0_IH.png): Normalized sensitivity index $S_x = \partial\log Y/\partial\log x$ of the 25 decomposed parameters (bars coloured by parameter group, as in Table 3), where $Y$ is the output being differentiated: $Y = \mathcal{R}\_{0}$ for the closed-form reproduction number in the left panel and $Y = Q\_{\mathrm{peak}}$ for the seasonal maximum of the infectious-human compartment of the calibrated model in the right panel. Left: closed-form reproduction number at the reference environmental state, by central differences with $h = 0.05$; the exact analytic values of Table 3 differ from these by at most $0.06$, the truncation error of the difference quotient. Right: seasonal maximum of the infectious-human compartment of the calibrated model, averaged over 2017-2023, same scheme. A positive index means the output increases with the parameter. The three _Anopheles_ suitability temperatures are exactly zero on the left because the thermal-suitability factor $f\_T$ is saturated at the reference climate.

[Figure 5](https://github.com/RaphaLevy/Environmental_Drivers_of_Malaria/blob/main/Figures/Paper/sobol_ih_qpeak_trimmed.png): First-order ($S\_i$) and total-order ($S\_{T\_i}$) Sobol' indices of the decomposed parameters for the output $Y = Q\_{\mathrm{peak}}$, the seasonal peak of the infectious-human compartment defined in Eq. (39), over the whole admissible parameter box of Table A.3 (Saltelli design, $N = 512$; bars coloured by parameter group). Only the 11 parameters with non-negligible sensitivity are shown; the 14 parameters with total-order index below $2.7\times 10^{-3}$, from $T\_{\min}^{\mathrm{p}}$ to $T\_{\mathrm{opt}}^{\mathrm{p}}$, are omitted from the plot. Each parameter has two overlaid bars: the darker inner bar is the first-order index $S\_i$ and the lighter outer bar is the total-order index $S\_{T\_i}$. The total-order index also collects the variance that a parameter carries through its interactions with the remaining ones, hence $S\_{T\_i} \geq S\_i$. Since $Q\_{\mathrm{peak}}$ is a maximum, the $74.4\%$ of the sampled parameter sets that are locally subcritical leave it at the initial value $I\_H(0)$; the indices therefore characterize the sampled box and not the height of an established endemic wave.
